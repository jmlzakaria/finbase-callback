# finbase-callback

Page de retour (GitHub Pages) pour l'application de bureau Finbase.

Après le consentement bancaire, la banque redirige le navigateur ici. La page transmet le code
reçu à l'application via le lien `finbase://callback`, ou l'affiche pour un copier-coller.

- Aucune donnée, aucun secret, aucun script externe, aucune statistique.
- Le code est à usage unique et inutilisable sans la clé privée conservée sur l'ordinateur de l'utilisateur.
- La page ne demande jamais d'identifiant ni de mot de passe.
